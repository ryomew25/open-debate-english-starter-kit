# Product Listing Notes (Seller Reference)

## Suggested title

Open Debate — React Debate Platform Starter Kit (English Edition)

## Accurate product summary

A responsive React + TypeScript front-end starter kit for a debate and discussion platform. Includes a warm editorial-style interface, debate discovery and creation screens, local demo voting and discussions, profiles, rankings, notifications, invitations, a sample moderation dashboard, and light/dark themes.

## Included files

- Full project source code
- Vite development and production build setup
- Fictional sample debates, messages, and comments
- Setup and deployment instructions in README.md
- Third-party attribution notes

## Important limitations to disclose

- Front-end starter kit only; no backend or hosted database is included.
- Demo data is saved in the current browser's localStorage only.
- No cross-user or cross-device synchronization.
- Nickname entry is not production authentication.
- The admin access check is not production authorization.
- Real-time collaboration and server-side moderation are not included.
- No separate end-user commercial license is included in this archive; define and review the license before sale.

Do not describe the project as a fully operational multi-user social network unless a backend and the required security controls have been added and tested.
